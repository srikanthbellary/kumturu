# Kumturu

Public history of Guntur for [kumturu.com](https://kumturu.com). Alias: kumuturu.com.

Static HTML on GitHub Pages (`main`, `/`). Story ends 15 August 1947.

- Pages: `index.html`, `the-name.html`, `timeline.html`, `ancient.html`, `medieval.html`, `independence.html`, `places.html`, `sources.html`
- Copy (source of truth): `copy/`
- Research briefs: `research/`
- Plate photographs: `media/plates-*.jpg`
- 1854 Pharoah & Co. District of Guntoor map: `media/guntoor-1854.jpg` (Internet Archive / California Digital Library, `atlasofsouthernp00phar`)
- Sada coin photographs: `media/coin-maha-sada.jpg`, `media/coin-siri-sada.jpg`, `media/coin-asaka-sada.jpg`

Atmosphere video bands look for `media/01-village-road.mp4`, `media/02-vengi-court.mp4`, `media/03-kondavidu.mp4`, and `media/04-krishna-country.mp4`. If a file is absent, the band holds as a still copper field. Those films are impressions, not archive evidence.

Regenerate HTML from the copy with `python3 build_site.py`.
